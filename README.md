# Cryptographie basée sur les codes : MDPC et Attaque ISD

Ce projet académique, réalisé en binôme dans le cadre de mon Master en cryptologie et sécurité de l'information, porte sur la cryptographie post-quantique. Il propose une implémentation en C du cryptosystème MDPC et de l'attaque par décodage d'ensembles d'information (ISD).

## Structure du code
* `MDPC.c` : Implémentation des mécanismes du cryptosystème MDPC.
* `ISD.c` : Implémentation de l'algorithme Information Set Decoding (ISD).
* `Inv_guauss.c` : Utilitaires mathématiques, notamment l'inversion de matrices via la méthode du pivot de Gauss sur des corps finis.
* `Rapport_de_projet_BOUAROUR_RAHMANI.pdf` : Rapport complet détaillant les concepts mathématiques, l'architecture logicielle et l'analyse de complexité.
